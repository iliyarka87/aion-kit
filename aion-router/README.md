# AION Router

Контролёр создаёт устойчивый план для одной задачи и только потом запускает
Codex. Он не является фоновой службой и не делает публикаций, коммитов,
отправки сообщений или внешних действий.

## Несколько чатов

У каждого чата своя `lane` — отдельная папка с планами и журналом. Выбор
модели и силы делается независимо для новой задачи в каждой lane.

```bash
python3 aion_router.py --lane aion-chat-1 plan task.json
python3 aion_router.py --lane aion-chat-2 plan task.json
```

Названия lane используют строчные латинские буквы, цифры, `_` и `-`. Они не
заменяют и не объединяют переписку чатов: нужны только чтобы Router не
смешивал их задачи.

## Защита расхода

1. Ручной маршрут `route` имеет приоритет над автоматическим выбором.
2. Автоматический выбор зависит от явного `family`, а не от ключевых слов в
   тексте задачи.
3. Astra не выбирается автоматически.
4. Любая запись требует `write_authorized: true`.
5. Внешнее действие блокируется всегда.
6. После запуска план ждёт отдельной проверки; отсутствие проверки не является
   причиной повышать модель.

## Пример задачи

```json
{
  "task_id": "AION-READ-001",
  "prompt": "Прочитай 00-START-HERE.md. Ничего не меняй. Ответь пятью пунктами.",
  "family": "inventory",
  "verification": "manual_read_only",
  "write": false,
  "workspace": "<AION_ROOT>"
}
```

Создать план:

```bash
python3 aion_router.py plan task.json
```

Запускать разрешается только сохранённый план:

```bash
python3 aion_router.py run <HOME>/Desktop/Projects/aion/aion-router/PLAN.json
```
