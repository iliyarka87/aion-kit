# AION Checklist

Механический замок на исполнение чек-листа. Не даёт перескакивать, не даёт
ставить зачёт себе и не даёт закрыть пункт без доказательств.

Это **замок, а не работник**: сам он ничего не строит и не решает. Строит
исполнитель, решает Директор, а Checklist следит, чтобы порядок не нарушили.

## Зачем он нужен

Мастер AION — 69 пунктов лестницей. Без замка любой участник рано или поздно
сделает одно из трёх: возьмёт пункт не по очереди, объявит себе успех, или
запишет «сделано» без улик. Всё три случались. Checklist делает их
невозможными механически, а не на доверии.

## Кого и как он держит

| | исполнитель | Директор | сам замок |
|---|---|---|---|
| выбрать пункт | **нет** | да, `dispatch` | — |
| вернуть исход | `PASS_CANDIDATE` · `FAIL` · `BLOCKED` | — | — |
| поставить `DONE` | **нет** | решает | **пишет только он** |
| без улик | — | **нельзя** | отказывает |
| второй пункт разом | **нет** | **нет** | `MAX_ACTIVE = 1` |
| перескочить | **нет** | **нет** | держит по `DEPENDS` |
| находка в стороне | записать | записать | запишет, работу **не сдвинет** |

Зачёт пишет **только контроллер** и только после решения Директора при
наличии требуемых улик. Ни исполнитель, ни Директор руками в состояние не
лезут.

## С чем его едят

Посмотреть:

```bash
python3 vorota.py status      доска одной строкой
python3 vorota.py list        все 69 пунктов со значками и зависимостями
python3 vorota.py current     что в работе: попытка, риск, какие нужны улики
python3 vorota.py history 20  последние записи летописи
```

Доска выглядит так:

```
69 ВСЕГО | 4 DONE | 0 ACTIVE | 6 READY | 59 LOCKED
ACTIVE: —
NEXT:   N-L0-04
PROJECT_COMPLETE: False
```

Значки: `✓` сделано · `▶` в работе · `○` готов · `·` заперт зависимостями ·
`?` ждёт проверки Директора · `✗` отказ.

Работать — полный круг одного пункта:

```bash
python3 vorota.py dispatch N-L0-04 --by director
python3 vorota.py report PASS_CANDIDATE --by worker --evidence вывод-проб.txt
python3 vorota.py validate N-L0-04 --by director --evidence вывод-проб.txt
# -> N-L0-04 DONE, назван ровно один следующий
```

Прочее:

```bash
python3 vorota.py finding "нашёл вот что" --by worker   записать, не трогая работу
python3 vorota.py complete                              завершён ли проект
python3 sobrat.py                                       собрать заново из источника
python3 sobrat.py --сверка                              определение = источнику?
python3 proby.py                                        31 проба
```

## Из чего состоит

```
vorota.py          сам замок
opredelenie.json   неизменное определение: 69 пунктов, зависимости, риск,
                   требуемые улики. Выведено из чек-листа, не придумано.
sostoyanie.json    живое состояние: кто сделан, кто готов, кто заперт
letopis.ndjson     летопись, только дозапись: DISPATCH · REPORT · DONE ·
                   NEXT_READY · FINDING
sobrat.py          сборка из источника и обратная сверка
proby.py           31 проба на десять свойств
```

Источник — `CHATGPT-DIRECTOR/MASTER-CHECKLIST-MIGRATION-1.md`, sha256
`73d447cadddf37be77df2d40af162e81508206fe421980fa6a43f8717f22f392`.
**Источник не меняется**: замок его только читает. Разошлось определение с
источником — `sobrat.py --сверка` скажет, и разбирается человек.

## Про время — принуждения нет, это решение владельца

Время записывается справочно: когда начали, сколько вышло, какой срок у
пункта по его риску (GREEN 20 · YELLOW 45 · RED 90 минут). **Замок по времени
ничего не решает** — не подгоняет, не проваливает, не закрывает. За временем
следит владелец.

Ранняя версия умела превращать просроченного кандидата в `TIMEBOX_EXCEEDED`.
Убрано по прямому слову владельца 19.09.2026.

## Чего он не делает

- Не выполняет пункты. Это замок, а не работник.
- Не судит о качестве работы — только о правах и наличии улик.
- Не чинит источник молча.
- **Не защищён от прямой правки файлов.** Состояние и код лежат там, где
  агенты пишут. Замок честен, пока никто не редактирует `sostoyanie.json`
  руками в обход. Настоящая защита — положить его под `root`, как золотую
  копию. На 19.09.2026 не сделано.
