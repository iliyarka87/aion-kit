# AION LOOP

Петля «Директор → исполнитель → судья → ворота», которая ведёт чек-лист AION-MASTER
без владельца-курьера. Собрана из живого канона AION-CONTROL 20 сентября 2026,
после того как прошла 27 пунктов из 69 за одну ночь и утро.

## Из чего состоит

| часть | что делает | где |
|---|---|---|
| **Связь** (AION Socket) | дверь в окно исполнителя без сети (AF_UNIX); идемпотентная доставка по ключу `item:attempt`; очередь с мёртвым письмом; восстановление после перезапуска | `svyaz/src/link.py`, `mailqueue.py`, `vosstanovlenie.py` |
| **Директор** | Codex пишет бриф, договор задачи проверяет поля, ворота выдают пункт, маркеры объявляются из словаря, доставка через очередь; суд — три голоса | `svyaz/src/director.py` |
| **Рука** (runner) | зовёт Директора и судью в нужный миг, напоминает, останавливается честно, журналирует start/end каждого хода | `svyaz/src/runner.py` |
| **Сторож** (watchman) | два глаза, три удара, четвёртый — к исполнителю; выключен по умолчанию | `svyaz/src/watchman.py`, `watch.py`, `svyaz/state/storoj-timer.sh` |
| **Судья** | inspect_ai + мост к локальному Codex, три чтения, зачёт при двух из трёх; метаданные личностей в каждом вердикте | `svyaz/sudya/` |
| **Ворота** (AION Checklist) | замок на чек-лист: один пункт в работе, DONE пишет только контроллер по решению Директора и с уликами, отказы в летопись | `checklist/` |
| **Почтовый ящик окна** | три модуля, кладущие письмо в живое окно Claude Code по паспорту сессии | `mailbox/` |
| **aionctl** | bootstrap / resume / reconcile / orient / gate / laws / context / routes | `bin/aionctl` |
| **Инструменты** | договор задачи, словарь маркеров, реестр отказов и проверка перед действием, улики с отпечатками, очередь решений владельца, наблюдаемость, приёмка канала, стабильное/кандидат/возврат, причинные следы и инварианты, регрессии по слоям, крючок ворот | `bin/*.py` |
| **Состояние** | машинное зеркало 05, схема, желаемое состояние | `state/` |
| **Данные-законы** | маршруты контекста, ось власти документов, классификация законов §32 | `data/` |
| **Реестры** | отказы (17 полей §5), решения, происшествия, образцы, методы, компания, продукты, журнал обмена (§23), очередь решений (§20), инварианты, следы, регрессии | `registries/` |
| **Публикация канона** | validate (документы + reconcile) → secret scan → private check → commit → push; launchd | `sync/` |
| **Документы** | 00 указатель, 01 Мастер, 09 план фазы | `docs/` |

Полный список файлов с отпечатками и источниками — `MANIFEST.json`. Проверка комплекта — `python3 proverit-komplekt.py`.

## Внешнее, что не копируется

- **Codex** — `/Applications/ChatGPT.app/Contents/Resources/codex` (app-server; потолок `/etc/codex/requirements.toml` под root — только чтение).
- **Судейское окружение** — отдельный Python 3.12 с `inspect_ai` (`requirements-sudya.txt`): `python3.12 -m venv ~/.aion-sudya/venv && ~/.aion-sudya/venv/bin/pip install -r requirements-sudya.txt`.
- **Claude Code** в VS Code — исполнитель; окно находится по паспорту `~/.claude/sessions/<pid>.json`.
- **/usr/bin/python3 3.9** — всё остальное, без сторонних пакетов.

## Как запускается

1. Канон с маркером `.aion-root` (см. `data/.aion-root`, `bin/aion_root`), `checklist/sobrat.py` строит свежую доску.
2. Открыто живое окно Claude Code — исполнитель. `python3 svyaz/src/link.py windows` его видит.
3. `nohup python3 svyaz/src/runner.py &` — рука ведёт круг: round → задача в окне → исполнитель докладывает `checklist/vorota.py report PASS_CANDIDATE --by worker --evidence …` → judge → DONE → следующий.
4. Сторож по слову владельца: `python3 svyaz/src/watchman.py pair --session … --thread …`, затем `bash svyaz/state/storoj-timer.sh`.
5. Ворота перед каждым действием — одной строкой в настройках владельца (шапка `bin/gate-hook.py`).

## Что пока держится на честности, а не на стене

Ворота и летописи лежат под тем же пользователем, что исполнитель; рука и сторож — из сессии, не под launchd. Это L3 и L5 чек-листа. Честное табло — `data/laws.json` (14 из 29 законов пока PROMPT_ONLY).
